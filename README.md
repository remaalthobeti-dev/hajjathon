# Hajjathon — بصيرة AI

هذا المستودع يحتوي على **نسختين مستقلتين تمامًا** من عرض "بصيرة AI" التفاعلي. كل نسخة عبارة عن نسخة كاملة ومنفصلة من الملفات (لا اعتماديات مشتركة، لا Symlinks) — تعديل إحداهما لا يغيّر الأخرى بأي شكل.

## البنية

```
hajjathon/
├── basira-original/   # نسخة كاملة ومستقلة من العرض الحالي
│   ├── index.html
│   ├── style.css
│   ├── script.js
│   ├── assets/
│   ├── slides/
│   └── README.md
└── basira-copy/       # نسخة مطابقة 100% لـ basira-original، لكن مستقلة عنها بالكامل
    ├── index.html
    ├── style.css
    ├── script.js
    ├── assets/
    ├── slides/
    └── README.md
```

كلا النسختين مطابقتان بايت-لبايت لحظة الإنشاء: نفس الشرائح (16 شريحة)، نفس التصميم والألوان والخطوط، نفس الحركات والانتقالات، نفس التفاعلات (خريطة العمليات الحية، محادثة الـ Hero، تبويبات "شاهد بصيرة أثناء العمل"، إلخ).

## الاستقلالية

- **لا ملفات مشتركة**: كل مجلد يحمل نسخته الكاملة من `index.html` / `style.css` / `script.js` / `assets/`.
- تعديل أي ملف داخل `basira-copy/` لا يغيّر أي ملف داخل `basira-original/`، والعكس صحيح — تم التحقق من ذلك عمليًا قبل الدفع.
- كل مجلد يعمل بشكل مستقل تمامًا (خادم محلي منفصل، لا استيراد بين المجلدين).

## التشغيل

لا حاجة لأي بناء (build). لكل نسخة خادم محلي منفصل:

```bash
# لتشغيل النسخة الأصلية
cd basira-original
python3 -m http.server 8080
# افتح http://localhost:8080

# لتشغيل النسخة الأخرى (في نافذة طرفية أخرى، أو بعد إيقاف السابقة)
cd basira-copy
python3 -m http.server 8081
# افتح http://localhost:8081
```

## التعديل

عدّلي أي نسخة بحرية — الملفات الثلاثة الأساسية داخل كل مجلد هي:

- `index.html` — محتوى وبنية الشرائح (16 شريحة)
- `style.css` — نظام التصميم (الألوان، الحركات، المكوّنات)
- `script.js` — كل التفاعلات (التنقل، الخريطة الحية، محادثات بصيرة، السيناريوهات)

أي تعديل يبقى محصورًا داخل المجلد الذي عدّلتِه فقط.

## التقنية

- **Tailwind CSS** (عبر CDN) — بدون أي أداة بناء.
- **RTL** بالكامل، خط **IBM Plex Sans Arabic**.
- رسومات SVG + CSS مبنية يدويًا (بدون مكتبات خرائط أو رسم خارجية).
- تنقّل بالنقاط الجانبية + دعم لوحة المفاتيح.
- حركات: Fade / Scale / Glow / Parallax عبر `IntersectionObserver`، مع محرّكات محادثة حية (typewriter) قابلة للإيقاف عند مغادرة الشريحة.
